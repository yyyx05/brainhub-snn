# 公开源码版本范围

项目采用Apache-2.0许可。公开仓库：[yyyx05/brainhub-snn](https://github.com/yyyx05/brainhub-snn)。

## 包含

生产105份SV与算法ROM、固定画像软件/JSON示例、离线决策回放HTML、原有测试/脚本、相关隔离候选源码、Vivado脚本、项目原生IP源码、精选结果与工程技能。

## 不包含

模型参数、数据集及派生测试资产：`models/`、`data/`、`fixtures/`、`imports/`、`memory/`和`tb/data/`均不收入公开版。这些资产在本地竞赛RAR中的部分副本不构成公开再分发授权。工具二进制、厂商库实现、许可文件、完整历史结果/DCP/波形也不分发。

JSON指纹选择和HTML回放不需要上述资产。真实模型仿真与算法评价须自行合法取得资产并按原目录配置。配置中的资产路径是接口约定，不是“文件已提供”声明。

原创代码许可见`../license.txt`，项目归属见`../notice.txt`。第三方材料保持各自权利。本仓库的生产源码没有因公开整理而改变；独立候选仍保持独立。
